## `build`

```bash
resumelang build [file] [flags]
```

| Flag | Default | Purpose |
| --- | --- | --- |
| `--out <dir>` | `dist` | Output directory. |
| `--formats <list>` | `html,json,md,txt` | Comma-separated subset of formats. |
| `--theme <name|path>` | from YAML | Override `meta.theme`. |

```bash
resumelang build resume.yml --formats html,pdf --out public
resumelang build jane.resume.yml --theme aurora
```

Output filenames mirror the input, with the `.resume` segment stripped:

| Input | Output base |
| --- | --- |
| `resume.yml` | `resume.html`, `resume.txt`, … |
| `jane.resume.yml` | `jane.html`, `jane.txt`, … |

## `serve`

```bash
resumelang serve [--port N] [--addr H] [--root DIR]
```

| Flag | Default | Purpose |
| --- | --- | --- |
| `--port` | `5500` | Listen port. |
| `--addr` | `127.0.0.1` | Bind address. Use `0.0.0.0` to expose on LAN. |
| `--root` | `cwd` | Project root that holds `web/`, `themes/`, `schema/`. |

OAuth env vars (optional — enable login providers):

```bash
RL_GITHUB_CLIENT_ID, RL_GITHUB_CLIENT_SECRET
RL_LINKEDIN_CLIENT_ID, RL_LINKEDIN_CLIENT_SECRET
RL_AUTH_SECRET             # 32+ bytes — HMAC for session cookie
```

## `validate`

```bash
resumelang validate resume.yml
```

Returns non-zero on schema errors. Warnings (missing `resumelang: v1` preamble,
unrecognized theme name) are printed to stderr but do not fail the command.

## Exit codes

| Code | Meaning |
| --- | --- |
| 0 | Success. |
| 1 | Generic error. |
| 2 | Schema validation failed. |
| 3 | Theme load failed. |
